維運筆記

兩層快取，位置不同

圖片優化快取在 node_modules/.astro/assets，會讓改過的圖在 build 時被舊版覆蓋； 內容集合快取在專案根目錄的 .astro/data-store.json。

schema 加欄位要清內容快取

新增欄位後 dev server 會讀到 undefined——舊 store 是用舊 schema 建的， Zod 驗證時把未知欄位剝掉。rm -rf .astro 才會生效，靜態建置不受影響。

比例要跟著圖檔實際尺寸

寫死的 ratio 與圖檔不符時，object-fit: cover 會靜靜裁掉內容。 作品集頁改成由 image.width/height 推導，換圖不用改程式。

透明插畫不要套圓角

Media 的 16px border-radius 會裁掉碰到邊角的圖案（鞋子、頭髮）。 去背後的插畫沒有矩形底，圓角只有壞處。
